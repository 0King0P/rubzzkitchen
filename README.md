# RubzzKitchen (`@rubzzkitchen`)

Halal Pakistani and Indian catering, architectural grazing tables, and artisan frozen appetizers in Carteret, NJ.

## Architecture

- `index.html` / `404.html`: Editorial application shell with Schema.org `FoodEstablishment` / `Catering` metadata, `?v=3` cache-busting, and relative `./` subpath resolution.
- `styles/tokens.css` & `styles/atelier.css`: Smoked Cardamom Noir & Brushed Atelier Brass 5-plane OKLCH design system with `Warm Parchment` (`sandstone-daylight`) theme toggle, asymmetric 12-column editorial gallery, and 2-column frozen dozen brasserie ledger.
- `assets/originals/`: Studio-enhanced 100% original `@rubzzkitchen` dish and client event photographs.
- `api/design-system.json`: Runtime token payload hydrated by `js/app.js`.
- `data/kitchen-data.js`: Authentic RubzzKitchen menu catalog, banquet packages, grazing stations, delivery zones, and event archive.
- `js/app.js`, `js/catering-architect.js`, `js/booking-engine.js`, `js/client-review-mode.js`: Tasting ledger, portion architect, grazing studio, freezer stash builder, and 4-step reservation desk.
